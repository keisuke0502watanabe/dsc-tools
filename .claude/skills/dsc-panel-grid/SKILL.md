# DSC Panel Grid

公開 URL: https://keisuke0502watanabe.github.io/dsc-tools/
ソース: リポジトリ直下の `index.html`(単一ファイル、外部依存は Google Fonts のみ)

ブラウザ内だけで動く。ファイルはどこにも送信されず、保存もされない(閉じると消える)。

## いつ使うか

- 複数の DSC 測定を**同じ軸・同じ配列**で並べて比較したい
- 温度プログラムが設定どおり実行されたか(熱履歴)を目で確認したい
- 昇温 / 降温 / 保持ごとの区間台帳やピーク一覧を CSV で欲しい
- 島津 TA-60 の `.tad` を、テキスト書き出しを経由せずそのまま読みたい

数値の最終確定(論文に載せる ΔH、校正済み温度)には使わない。後述の注意を参照。

## ユーザーへの案内手順

1. 上の URL を開いてもらう(ローカルなら `index.html` をダブルクリックでも動く)。
2. 左上の枠に測定ファイルをまとめてドロップ。`.tad` `.txt` `.csv` を受け付ける。
3. 左のリストで**ドラッグして並べ替え**、名前を**その場で書き換え**る。並び順と名前がそのままパネルの位置と見出しになる。
4. 上部タブでビューを選ぶ(下表)。
5. 必要なら左のパラメータを調整し、右下の「書き出し」ボタンで保存。

| タブ | 内容 | 主な用途 |
| --- | --- | --- |
| 熱履歴 T vs t | 実測温度の時間変化。区間を色分け、番号付き | プログラムが設定どおりか、折り返し位置の確認 |
| 熱流 vs 時間 | 全区間の熱流 | いつ何が起きたかの追跡 |
| 熱流 vs 温度 | 昇降温のみを温度軸で重ね書き | ピーク位置の比較 |
| 熱流 vs 温度(段積み) | ステップごとに縦オフセット。左上にスケールバー | 発表用の図 |
| 定温保持のみ | 保持区間だけを保持開始からの経過時間で | 等温結晶化、転移の誘導時間 |

## パラメータの意味と触りどころ

**信号**
- 質量で規格化 W/g: ヘッダの試料量で割る。面積比較には必須。質量が読めないファイルは mW のまま。
- 吸熱を上向きに: 既定 ON。島津は生データが吸熱下向きなので読み込み時に反転して Pyris と揃えてある。
- 平滑化 点数: 移動平均。奇数。ピーク位置がずれるので、数値を読むときは 1 のまま。

**セグメント判定**(温度の時間微分から昇温 / 降温 / 保持を自動分割)
- |dT/dt| 閾値(既定 0.35 K/min): これより速ければ昇降温、遅ければ保持。ゆっくりした昇温(0.5 K/min 等)が保持扱いになるなら下げる。
- 最短 min(既定 0.8): これより短い区間は捨てる。折り返し付近の細切れ対策。
- 端の除外 min(既定 0.4): 各区間の頭を捨てる。切り替え直後の過渡応答を落とす。熱履歴ビューには効かない。
- 色/段の基準: 「末尾から揃える」で最終降温・最終昇温が全パネルで同色・同高さになる。ステップ数の違う測定を並べるときはこちら。「先頭から揃える」は 1st 昇温を基準にする。

**軸**: 全パネル共通。自動を外すと手入力。基準線はカンマ区切りで複数指定可(例 `33.5, 26`)、温度軸ビューにだけ引かれる。

**レイアウト**: 列数とパネル寸法。6 測定を 3 列にすれば 2×3。

## 出力ファイル

| ボタン | ファイル名 | 内容 |
| --- | --- | --- |
| SVG | `<title>_<view>_<stamp>.svg` | 画面と同じベクタ。Illustrator で編集可。論文用 |
| PNG | `<title>_<view>_<stamp>.png` | 3 倍解像度。Web フォントは埋め込まれず、日本語はシステムフォントに置き換わる |
| CSV 台帳 | `dsc_ledger_<stamp>.csv` | 1 行 1 セグメント |
| CSV ピーク | `dsc_peaks_<stamp>.csv` | 1 行 1 ピーク(セグメントあたり最大 4 件、|ΔH| 降順) |
| CSV 波形 | `dsc_curves_<stamp>.csv` | 間引いた波形(セグメントあたり最大約 3000 点) |

CSV は UTF-8 BOM 付き、CRLF。Excel でそのまま開ける。

### CSV 台帳の列
`file, label, sample, mass_mg, date, vendor, step, type, T_start_C, T_end_C, rate_K_min, duration_min`
- `step`: 昇降温は `1st` `2nd` …、保持は `hold`
- `type`: `heating` / `cooling` / `isothermal`
- `vendor`: `shimadzu` / `pyris`

### CSV ピークの列
`file, label, mass_mg, step, type, direction, T_onset_C, T_peak_C, T_end_C, dH_J_per_g(または dH_mW_min), normalised, endo_up`
- `direction`: `endo` / `exo`。`dH` の符号は発熱が負
- `normalised` と `endo_up` に書き出し時の設定が残るので、集計前に必ず確認する

### CSV 波形の列
`file, label, step, type, time_min, temp_C, heatflow_W_per_g(または heatflow_mW)`

## CSV を受け取って集計するとき

- まず `normalised` / `endo_up` 列(ピーク CSV)か熱流列の列名(波形 CSV)で単位と向きを確認する。混在していたら揃えてから比較する。
- 同じ `file` 内でセグメントを比べるのは安全。ファイル間で温度を比べるときは温度校正の状態を聞く。
- ΔH は直線ベースラインの自動積分。隣接ピークの裾が混ざると 20〜30 % ずれる。順位づけと傾向の議論までに留め、論文に引く値は手積分を促す。
- 小さな肩(セグメント内の最大振幅の 6 % 未満)は検出されない。見落としの可能性があるときは波形 CSV を見る。
- 保持区間の誘導時間などを出したいときは、台帳 CSV の `isothermal` 行と波形 CSV の該当 `step` を突き合わせる。

## 対応フォーマットの要点

- `.tad`: 島津 TA-60 バイナリ、`TA-60 FILE VER2.xx`。チャネル 1=時間(s)、2=温度、4=DSC(mW)、3=プログラム温度(あれば)。ヘッダから試料名・収集日・試料量・ガス流量を拾う。
- 島津テキスト: UTF-16LE の日本語ヘッダ(`[ファイル情報]` `[測定プログラム]` `[データ]`)。`Time / Temp / DSC` 列。
- Pyris テキスト: `Time  Unsubtracted …` 行以降がデータ。`Sample Temp` 列と `Uncorrected Heat Flow` 列を使い、メソッド行(`1) Heat from … to … at …`)からステップを拾う。
- 熱流の向きは読み込み後、吸熱上向きに統一される。

パーサは DSC Analyzer v10 と同じ実装なので、同じファイルは同じ行に落ちる。

## 注意(必ずユーザーに伝える)

- **温度は補正していない。** 装置校正のずれはそのまま出る。同一測定内の相対位置は影響を受けない。校正はインジウム 156.6 °C で。
- **ΔH は参考値。** 上記のとおり。
- データはブラウザを閉じると消える。設定も保存されない。再現したければ書き出した CSV とパラメータをメモしておく。

## ツール自体を直すとき

`index.html` 1 ファイル。セクション見出しのコメントで 1 パーサ、2 セグメント分割・ピーク検出、3 状態、4 SVG 描画、5 画面、6 読み込み、7 書き出し、8 配線に分かれている。`main` または現在のデフォルトブランチへ push すると GitHub Actions で自動デプロイされる。
