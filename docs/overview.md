# DSC Panel Grid 概要

複数の DSC 測定ファイルをブラウザにドロップし、同じ軸・同じ配列のパネル図にして SVG / PNG / CSV で書き出す単一 HTML のツール。

- 公開 URL: https://keisuke0502watanabe.github.io/dsc-tools/
- 実体: リポジトリ直下の `index.html`(約 57 KB、依存は Google Fonts のみ)
- 処理はすべてブラウザ内。ファイルは送信も保存もされない。

## 目的

- 島津 TA-60 の `.tad` を、テキスト書き出しを介さずフル精度で読む
- 島津と PerkinElmer Pyris の測定を同じ向き・同じ単位に揃えて並べる
- 昇温 / 降温 / 保持の区間を自動で切り分け、番号を振って色分けする
- 図と一緒に、区間台帳・ピーク一覧・波形の CSV を出す

## 入力

| 形式 | 判別 | 備考 |
| --- | --- | --- |
| 島津 `.tad` | 先頭が `TA-60 FILE VER2.` | バイナリを直接デコード。時間・温度・DSC・(あれば)プログラム温度、ヘッダの試料名・収集日時・試料量・ガス流量 |
| 島津 `.txt` | `[データ]` セクション、または `機種名:` `試料名:` の行 | UTF-16LE / UTF-8 の BOM を自動判別 |
| Pyris `.txt` | `Time  Unsubtracted …` のデータ見出し | `Sample Temp` と `Uncorrected Heat Flow` を使用。メソッド行からステップも取る |

島津は生データが吸熱下向きなので、読み込み時に符号を反転して Pyris と揃える。

## 画面の構成

左サイドバーにファイル一覧とパラメータ、右にタブ付きの図と区間テーブル。

### ビュー(タブ)

| タブ | X 軸 | Y 軸 | 描くもの |
| --- | --- | --- | --- |
| 熱履歴 T vs t | 時間 | 試料温度 | 全区間。保持は灰色、昇降温は段ごとの色と番号 |
| 熱流 vs 時間 | 時間 | 熱流 | 全区間 |
| 熱流 vs 温度 | 温度 | 熱流 | 昇降温のみ重ね書き |
| 熱流 vs 温度(段積み) | 温度 | 熱流(オフセット) | 昇降温を縦にずらして積む。同じ段は全パネルで同じ高さ。左上パネルにスケールバー |
| 定温保持のみ | 保持開始からの時間 | 熱流 | 保持区間のみ |

軸範囲は全パネル共通。基準線(縦の破線)は温度軸のビューにだけ引かれる。

### パラメータ

| グループ | 項目 | 既定 | 意味 |
| --- | --- | --- | --- |
| レイアウト | 列数 / パネル幅 / パネル高 / タイトル | 3 / 420 / 280 / 空 | 図の配列と寸法 |
| 信号 | 質量で規格化 | ON | 試料量で割って W/g。質量が無ければ mW |
| 信号 | 吸熱を上向きに | ON | OFF で装置の生の向き |
| 信号 | 平滑化 点数 | 1 | 移動平均。奇数 |
| セグメント判定 | \|dT/dt\| 閾値 | 0.35 K/min | 昇降温と保持の境界 |
| セグメント判定 | 最短 min | 0.8 | これより短い区間は捨てる |
| セグメント判定 | 端の除外 min | 0.4 | 各区間の頭を捨てる(過渡応答) |
| セグメント判定 | 色/段の基準 | 末尾から揃える | 最終昇降温を基準に色と段を合わせる |
| 軸 | X / Y の自動と範囲、基準線 | 自動 | 基準線はカンマ区切りで複数可 |
| 表示 | ステップ番号 / 矢印 / 保持区間 / 試料量 / ゼロ線 | すべて ON | 図中の注記 |

## 処理の流れ

1. **読み込み**: `.tad` はバイナリをデコードして島津テキスト形式に変換してから、テキストと同じパーサに通す。
2. **前処理**: 符号(吸熱上向き)、質量規格化、平滑化。
3. **セグメント分割**: 温度を 41 点移動平均してから ±8 点の差分で dT/dt を求め、閾値で +1 / 0 / −1 にラベル付け。ラベルを 61 点移動平均で整えてから、最短時間未満の区間を捨てる。昇降温に 1st, 2nd … と番号を振り、末尾からの番号も持つ。
4. **ピーク検出**(テーブルとピーク CSV): 各区間内で、MAD による外れ値除去つきの直線ベースラインを 6 回反復で当て、そこからのずれの極大を拾う。閾値は区間内の最大振幅の 6 %。端 2 % は無視。台形積分で ΔH を出し、|ΔH| 0.4 未満は捨てる。区間あたり最大 4 件。
5. **描画**: SVG を直接組み立てる。線は 1 区間あたり最大 1600 点に間引く。
6. **書き出し**: SVG はそのまま、PNG は 3 倍で Canvas 経由、CSV は UTF-8 BOM 付き CRLF。

## 出力

| ボタン | ファイル名 | 列 / 内容 |
| --- | --- | --- |
| SVG | `<title>_<view>_<yyyymmdd_hhmm>.svg` | 画面と同じベクタ |
| PNG | 同 `.png` | 3 倍解像度。Web フォントは埋め込まれない |
| CSV 台帳 | `dsc_ledger_<stamp>.csv` | file, label, sample, mass_mg, date, vendor, step, type, T_start_C, T_end_C, rate_K_min, duration_min |
| CSV ピーク | `dsc_peaks_<stamp>.csv` | file, label, mass_mg, step, type, direction, T_onset_C, T_peak_C, T_end_C, dH_J_per_g または dH_mW_min, normalised, endo_up |
| CSV 波形 | `dsc_curves_<stamp>.csv` | file, label, step, type, time_min, temp_C, heatflow_W_per_g または heatflow_mW。区間あたり最大約 3000 点に間引き |

`step` は昇降温が `1st` `2nd` …、保持が `hold`。`type` は `heating` / `cooling` / `isothermal`。ΔH の符号は発熱が負。

## 制限と注意

- **温度は無補正。** 装置の校正ずれはそのまま出る。同一測定内の相対比較には影響しない。
- **ΔH は直線ベースラインの自動積分。** 隣接ピークの裾が混ざると 20〜30 % ずれる。論文に引く値は手で積分し直す。
- 小さな肩(最大振幅の 6 % 未満)は検出されない。
- 平滑化するとピーク位置がずれる。数値を読むときは 1 のまま。
- PNG では日本語がシステムフォントに置き換わる。編集や印刷用途は SVG。
- 設定とデータはブラウザを閉じると消える。
